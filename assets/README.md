# Images carried with the README

## `pixi-logo.svg`

The pixi logo, vendored rather than hot-linked. The README uses it as the link to pixi's
installation instructions, and a logo that lives at someone else's URL is a broken image the
day that URL moves — on the one page a reader who has never used pixi will be looking at.

It is a self-contained SVG: no raster data, no external references, so it renders from a
clone with no network.
